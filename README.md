# Lumi (ሉሚ)

Lumi is an Ethiopia-first, Android-first women's menstrual-cycle and fertility-awareness app. It helps users record cycle observations, understand fertility patterns, and make informed decisions using natural family-planning education.

## Planned features

- Menstrual-cycle and period tracking.
- Daily fertility observations, including basal body temperature, cervical mucus, and symptoms.
- Fertility-awareness guidance that distinguishes potentially fertile, lower-fertility-likelihood, and uncertain days.
- English and Amharic interfaces, with natural Amharic script.
- Conservative handling of irregular cycles, postpartum and breastfeeding situations.
- An integrated women's shop with product listings, orders, delivery tracking, and admin management.

## Important safety limitations

Lumi provides educational fertility-awareness estimates; it does **not** guarantee pregnancy prevention and must not label any day as completely "safe" or guaranteed infertile. Calendar estimates alone cannot confirm infertility. Missing observations, irregular cycles, postpartum changes, breastfeeding, illness, sleep disruption, and other factors can make fertility status uncertain. Users seeking to avoid pregnancy should learn a validated fertility-awareness method from a qualified educator or healthcare professional and should not rely solely on app predictions.
